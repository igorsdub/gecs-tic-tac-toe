# Tic-tac-toe

A two-player game for one device. Open `index.html` in a browser to play; no installation is needed.

X starts. Players take turns placing marks on the 3×3 board, and the first to make a row, column, or diagonal wins. A full board without a winner is a draw. Use **New game** at any time to clear the board and start again as X.

The phone-friendly board supports touch, mouse, and keyboard. Pink Xs and blue Os use Lily's soft pastel palette, with readable text and clear turn and result messages. Winning squares are highlighted, and marks animate subtly. There are no sounds or scorekeeping.
